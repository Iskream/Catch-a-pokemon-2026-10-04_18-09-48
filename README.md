# Roll a pokemon!
## [!IMPORTANT] Versão Unity: 2022.3.52f1
<br>
Olá, Os alunos de jogos digitais, Brenda Santos Pinheiro e Thiago Lopes da UNEB, se propuseram a fazer um minigame inspirado no roll a ball para a aula de prototipagem-para-jogos sob a orientação de Murillo Boratto.
<br>
Link para explicação detalhada em vídeo: https://youtu.be/zh34ohwXnug?si=EZg3o8oqLXy3DJgg
<img width="1382" height="700" alt="image" src="https://github.com/user-attachments/assets/97319597-380f-44c3-a0fb-c2aa77e28603" />
<br>
Resumo: A pokebola deve coletar todos os pokemons no mapa para ganhar o jogo!
<ol>
  <li=2>
    Assets usados:
    <br>

  </li>
</ol>
<ol=2>
  <li>
    Scripts (mais informações na pasta vs):
    <br>
    “PlayerController” que contem todas as informações que a pokebola(esfera) deve ter como : movimentação, colisão, atributos e textos:
    <br>
    “CamaraController” cujo o conceito é fazer a câmera seguir o jogador durante o percurso.
    <br>
    “Rotator” é o script que faz os pokemons girarem na horizontal.
    <br>
    "musica" que é o script que permite que usando os objetos como referência, quando o player colidir com eles, cada pokemon emita um som diferente.
  </li>
</ol>
<ol=3>
  <li>
    Musica de fundo: é o bgm de pallet. Caso queira remover, procure na hierarquia e abaixe o volume. 
  </li>
</ol>
